# 业务功能

## 角色

| 角色 | 能做什么 |
|---|---|
| 系统管理员 | 管理账号、角色与权限、数据字典、系统参数，查看操作日志 |
| 项目经理 | 创建与归档项目，邀请成员并分配权限，划分阶段，创建与指派任务，调整排期，查看报表与延期预警 |
| 普通成员 | 更新任务状态与进度，上传文档，参与讨论 |
| 测试人员 | 普通成员的全部功能，加上登记缺陷与回归验证 |
| 访客 | 只读 |

项目内另有四项权限开关：编辑任务、调整排期、编辑文档、管理成员，由项目经理按人设置。

## 主流程

建项目 → 邀请成员 → 划分阶段 → 建任务、设依赖 → 指派（可用分配建议）→ 成员更新进度 → 看板、甘特图、燃尽图跟踪 → 延期预警 → 缺陷登记与修复 → 统计收尾。

## 模块与代码

开题报告的 8 个模块对应 10 个 Java 包（`org.miniteam.pms.*`）：「用户与权限管理」拆为 `auth`、`user`，「团队协作」拆为 `collab`、`defect`。

| 模块 | 功能点 | Java 包 | 数据表 | 接口分组 | 页面 |
|---|---|---|---|---|---|
| 用户与权限管理 | 注册与登录、JWT 鉴权、个人信息 | `auth` | `sys_user` | 认证 | 登录、系统设置·个人 |
| | 用户管理、角色管理、权限分配 | `user` | `sys_user`、`sys_role` | 用户管理、角色权限 | 系统设置·人员、角色与权限 |
| 项目管理 | 项目创建/编辑、归档、成员管理、成员角色与权限、概览、往期日报 | `project` | `project`、`project_member`、`daily_issue` | 项目、成员、往期日报 | 顶栏项目切换、概览、成员与权限、往期日报 |
| 任务管理 | 任务创建、指派、工期与状态、子任务拆分、依赖、看板拖拽、优先级评分 | `task` | `task`、`task_dependency` | 任务、依赖 | 任务看板、任务详情、概览·今日待办 |
| 进度跟踪 | 里程碑、甘特图、关键路径、进度百分比、延期预警 | `progress` | `milestone` | 进度、里程碑 | 进度、概览·关键路径与头条 |
| 统计报表 | 燃尽图、完成率与按期率、延期率、工作量分布、缺陷密度、负载均衡建议 | `report` | 无，读取 `task`、`defect`、`sys_user` | 统计报表 | 统计报表、成员与权限·本周工时 |
| 团队协作 | 讨论与评论、项目动态、站内通知 | `collab` | `discussion`、`comment`、`notification` | 团队协作、通知 | 团队协作、任务详情·讨论、顶栏通知 |
| | 缺陷记录、缺陷关联任务、回归验证 | `defect` | `defect` | 缺陷 | 团队协作·缺陷 |
| 文档管理 | 上传与下载、分类、版本记录、关联项目/任务 | `document` | `document`、`document_version` | 文档 | 文档、任务详情·文档 |
| 系统管理 | 操作日志、基础配置、数据字典、算法权重配置 | `system` | `operation_log`、`sys_dict`、`sys_config` | 系统管理 | 系统设置·日志、字典、系统参数 |

通用代码在 `common` 包：统一响应体 `Result`、分页 `PageResult`、响应码 `ResultCode`、业务异常 `BusinessException`、全局异常处理。

## 核心算法

| 算法 | Java 包 | 输入 | 输出 | 接口 | 页面 |
|---|---|---|---|---|---|
| 任务优先级评分 | `task` | 重要度、紧急度、截止日期、预估工期、被依赖数、是否在关键路径，`sys_config` 中的权重 | 0–100 得分、今日待办 Top N | `/todo`、`/priority-ranking` | 概览·今日待办、看板卡片优先级 |
| 关键路径与进度预测（CPM） | `progress` | 任务工期、依赖、实际完成情况 | 各任务时间参数与总时差、关键路径、预测完工日期、延期天数 | `/gantt`、`/critical-path` | 进度、概览·关键路径与头条、延期预警通知 |
| 成员负载均衡与分配建议 | `report` | 成员技能与未完成任务工时、待分配任务所需技能 | 建议负责人、分配前后负载与方差 | `/workload`、`/assign-suggestions` | 新建/编辑任务的指派、统计报表 |

## 系统边界

不做：移动端、多租户、支付、独立实时推送、CI 平台、单点登录、复杂审批流。
